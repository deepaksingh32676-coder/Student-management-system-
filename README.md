Student Record System (C++)

A simple Student Record Management System built using C++. This is a menu-driven console application that allows users to manage student data efficiently with basic operations like adding, displaying, searching, and deleting records.

📌 Features

➕ Add new student records

📋 Display all student details

🔍 Search student by ID

❌ Delete student record

🧭 Simple menu-driven interface

🛠️ Technologies Used

Language: C++

Concepts Used:

Structures (struct)

Arrays

Functions

Loops and Conditional Statements

📂 Program Structure

🔹 Student Structure

Stores student details:

ID

Name

Age

Marks

🔹 Functions Included

addStudent() → Adds a new student

displayStudents() → Displays all records

searchStudent() → Searches a student by ID

deleteStudent() → Deletes a student record

▶️ How to Run

Copy the code into a file named:

student_record.cpp

Compile the program:

g++ student_record.cpp -o student_record

Run the program:

./student_record

💡 Example Menu

--- Student Record System ---
1. Add Student
2. Display Students
3. Search Student
4. Delete Student
5. Exit

⚠️ Limitations

Stores data only temporarily (no file/database storage)

Maximum limit of 100 students

Name input does not support spaces
